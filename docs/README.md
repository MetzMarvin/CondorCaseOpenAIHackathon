# Hackathon-Dokumentation

- [Hackathon-Plan](hackathon-plan.md): Problemstatement, Ziele, MVP, Architektur, Salesforce-Dummy, Datenkonzept, Kennzahlen und Demo-Ablauf.
- [Visueller Plan](visual-plan.html): interaktive Übersicht mit „Einfacher Fall“, „Beleg fehlt“, „Schwerwiegender Fall“ und „Verärgert, aber klar“. KI stellt klare Rückfragen selbst und bearbeitet unterstützte Fälle automatisch. Menschen übernehmen bei Fähigkeits-/Befugnisgrenzen oder schwerwiegenden Sachverhalten. Die Sentimentanalyse der Kundentexte unterstützt Tonalität und Priorisierung; Stimmung allein löst keine Übergabe aus.
- [Editierbare Visualisierungsquelle](visual-plan.fragment.html): ursprüngliches HTML-Fragment für spätere Änderungen; die direkt öffnbare Version ist `visual-plan.html`.

## Öffnen

`visual-plan.html` direkt im Browser öffnen. Es sind kein Build, keine Installation und kein Anwendungsserver erforderlich. Auf macOS vom Repository-Hauptverzeichnis aus:

```sh
open docs/visual-plan.html
```

Die Visualisierung erklärt den geplanten Ablauf und ist keine implementierte Ticketanwendung. Die 3.000 synthetischen Fälle sind im Plan spezifiziert und noch nicht erzeugt.
